# TRAWIQ Security

### Think Beyond Traffic.

TRAWIQ Security is an AI-powered Network Intrusion Detection System (NIDS).

## Project Goals
- Analyze network traffic.
- Detect suspicious network activities.
- Identify potential cyberattacks.
- Generate security alerts.
- Use Machine Learning for anomaly detection.
- Provide AI-assisted security alert explanations.

## Technologies
- Python
- Scapy
- Pandas & NumPy
- Scikit-learn
- FastAPI
- React
- PostgreSQL

Currently under development.
