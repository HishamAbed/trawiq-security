# Instructions for AI Coding Agents

You are contributing to TRAWIQ Security, an AI-powered Network Intrusion Detection
and Threat Intelligence project.

## Non-negotiable rules
- Read `README.md`, `docs/ARCHITECTURE.md`, and `docs/PROJECT_CONTRACT.md` before coding.
- Work only on the module assigned in the task. Do not rewrite unrelated modules.
- Do not change public function names, data contracts, or package layout without first
  proposing the change and updating the contract.
- Do not invent model performance, detection capabilities, or completed features.
- Keep datasets, packet captures, trained model binaries, credentials, and local
  environment files out of Git unless the team explicitly approves a small safe sample.
- Never capture or analyze traffic on networks without authorization.
- Add or update tests for every behavior change.
- Explain assumptions and list files changed in your final report.
- Do not merge or push directly to `main`.

## Development workflow
1. Confirm the assigned member/module and expected inputs/outputs.
2. Inspect existing code before editing.
3. Implement the smallest coherent change.
4. Run relevant tests and report exact commands/results.
5. Do not silently alter another member's files.
